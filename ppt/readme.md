PIEDRA PAPEL TIJERA EN PYTHON

## Características

- Implementa las reglas clásicas del juego
- Sistema de puntuación por partidas
- Estadísticas de la sesión
- Interfaz simple en la terminal

## Requisitos

- Python 3.x
- Terminal o consola

## Instalación

1. Clonar el repositorio:

git clone 

2. Entrar en la carpeta del proyecto:

cd ppt/src

## Ejecución

Ejecuta el archivo principal:

python juego.py


## Cómo jugar

1. El jugador elige:
   - Piedra
   - Papel
   - Tijera

2. La computadora selecciona una opción aleatoria.

3. Se determina el ganador según las reglas:
   - Piedra vence a Tijera
   - Tijera vence a Papel
   - Papel vence a Piedra

4. El juego muestra el resultado y actualiza las estadísticas.
